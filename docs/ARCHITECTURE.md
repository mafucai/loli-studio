# ARCHITECTURE — loli-studio

## 当前架构

手机浏览器打开 `prototype/index.html`。页面不使用构建工具，脚本按固定顺序加载。

用户操作进入 `actions.js`，动作调用 `factory.js` 或 `ai.js`，结果经 `store.js` 保存，再由 `main.js` 调用 `render.js` 重绘。

## 数据流

1. 设计词生成结构化设计。
2. 出图生成候选图并等待人工通过。
3. 拆件生成物料、工序和成本基础。
4. 查重给出演示相似度，人工决定是否标原创。
5. 采购生成官方搜索入口和演示价格。
6. 组合、模特、工厂、成本依次读取前序结果。

缺少前序结果时，动作停止并提示，不自动补假的“已完成”状态。

## 真实与演示

- 没有 Base URL 和 API Key 时只走演示模式。
- 有配置时，`ai.js` 才请求兼容接口。
- 请求失败必须返回错误，不能改写成演示成功。
- 当前图片仍是本地 SVG 占位，不能称为真实出图。

## 后续边界

Android 只增加 WebView 容器、返回键和本机存储桥。业务计算继续留在现有 JavaScript。签名和 APK 只在 GitHub Actions 生成。
