# 洛丽塔工坊 APP 用户手册

版本：与 build-25 对应（提交 31e345d）| 适用：Android WebView 壳 APK

---

## 一、这是什么 App

洛丽塔商家从**设计到预售回款**的闭环记账工具：

设计词 → 出图 → 图透投票 → 拆件 → 查重 → 采购 → 组合 → 模特 → 工厂 → 成本利润 → 定样定价 → 预售开团 → 统计看板。

**三条边界（App 永远不做）**：
1. **不收款** —— 只记账，钱走平台。
2. **不自动通知** —— 所有清单（催款/退款）只生成，由你去平台操作。
3. **不代替平台** —— 退款、发货等真实动作在电商平台完成。

**隐私硬约束**：订单**不存**姓名、电话、地址，只有匿名 ID。真实单号只在「发货 / 退款 / 对账」时录入。

---

## 二、开始前：配接口

App 的 AI 功能（设计词、出图、查重等）需要你自己的接口：

1. 底部进 **设置** 页。
2. **两个池分开配**：文本接口（设计词/分析）与图片接口（出图），互不污染。
3. 每个池可存多套（名称 + 地址 + 密钥 + 模型），点一个设为当前。
4. 删除接口会弹确认框（APK 里已修好，会正常弹出），确认后才删。

## 四、设计主线（第 0~10 步）

| 步 | 页面 | 你做什么 | 关键按钮 |
|---|---|---|---|
| 0 | 企划 | 定主题风格 + 柄图方向 + 避免词 | 选完进设计词 |
| 1 | 设计词 | AI 生成设计词（避开避免词） | 生成 / 下一步·出图 |
| 2 | 出图 | AI 出图 | 下一步·图透 |
| 3 | 图透 | 多版本投票选图 | 投票 / 下一步·拆件 |
| 4 | 拆件 | 拆分部件 | 下一步·查重 |
| 5 | 查重 | 平台查重比对 | 标记原创 → 下一步·采购 |
| 6 | 采购 | 录真实采购价（只统计你填的） | 下一步·组合 |
| 7 | 组合 | 组合实况 | 下一步·模特 |
| 8 | 模特 | 模特细节 | 下一步·工厂 |
| 9 | 工厂 | AI 搜代工厂线索（仅供参考）+ 记录真实工厂 | 选这家 → 下一步·成本 |
| 10 | 成本 | 填售价/佣金/快递/包装/固定费/数量 | 计算 → **下一步·定样定价** |

> 每一步的「下一步」按钮**只有完成该步后才出现**（比如成本页要算出结果才给进定样）—— 这是故意的，防止跳步。

## 五、定样定价（第 11 步）

1. 成本依据自动带出（单件成本来自第 10 步）。
2. 填：**公布价**（对外售价，可与成本页测算价不同）、**定金比例**、**工期**、**成团截止日期**。
3. **分色成团线**：每个颜色一行，默认 1000 件/色，可逐色覆盖（分色成团是行业主流，不是可选项）。
4. 点 **生成定样** → 出定金/尾款/保本件数/满额利润。
5. 点 **下一步 · 预售开团**。

## 六、预售线（第 12 步，核心）

### 开团
点 **开团（按颜色建批次）** → 每个颜色自动建一团。

### 录定金单
批量录入，每行一条：`颜色,数量,金额`（逗号/顿号/Tab 都行）。
App 不收款，这里只记账；**不存买家姓名电话地址**。

### 成团进度
按 **颜色 × 批次** 逐行显示：已成团 / 成团线 / 百分比。
成团率 = 该颜色该批次的实际件数 ÷ 目标件数（**按行判定，不按整个款**）。

### 成团判定
点 **判定成团**（截止日前也可提前判）→ 每行显示 成团 / 流团。
- 部分成团：够线的颜色正常做，不够线的单独流团。
- 款状态会提示「判定后应为 ×××」，点按钮同步。

### 流团退款
点 **生成退款清单** → 应退总额 + 逐单明细（匿名 ID）。
**App 不自动退款**，你拿清单去平台退，退完点 **标记为已退款**。

### 履约（同页下方）
| 动作 | 说明 |
|---|---|
| **大货** | 成团后推款状态：已成团 → 生产中 → 已发货 |
| **补尾款** | 待尾款单；超期可 **标记尾款逾期** → 生成催款清单（不自动发） |
| **发货** | 待发货 → 已发货；**发货后才允许录真实单号** |
| **售后** | 登记售后（14 类原因）+ 统计分布 |

### 看板（第 13 步）
预售页底部点 **下一步 · 统计看板**。数据**即时计算**，不用手动刷新。

**阈值表（「阈值触发 → 动作」）**：

| 指标 | 阈值 | 触发方向 | 动作 |
|---|---|---|---|
| 成团率 | < 100% | 低于 | 流团：退定金、发流团通知、关批次 |
| 定金转化率 | ≥0.8% 正常 / 0.3~0.8% 预警 / <0.3% 异常 | 低于 | 预警标黄+对比+查详情页；异常标红+暂停推广+预警流团风险 |
| 退款率 | ≥15% 预警 / ≥25% 异常 | **高于** | 预警标黄+拆款/批次+拉原因；异常标红+暂停推广+客服介入+查尺码表 |

> UV（访客数）**只显示「待录」**，不参与触发、不假算。有真实 UV 再录。

## 七、常见问题

**Q：算出来的东西会丢吗？**
所有数据存在手机本地。若存储写不进去（空间满/隐私模式），会**弹提示**并进报错助手 —— 看到请立即处理。

**Q：流团了怎么办？**
按颜色×批次判定，只流不够线的颜色。生成退款清单 → 平台退款 → 标记已退款。够线颜色不受影响。

**Q：能开第二个款吗？**
能。历史页点 **＋ 新建设计单**，多款并行是常态，各款独立成团。

**Q：出错了怎么反馈？**
点报错角标，错误面板有时间和来源；复制按钮可一键复制全部错误发给别人。
